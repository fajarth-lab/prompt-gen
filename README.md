# DeepRPP SMP — Studio Perancang RPP Pembelajaran Mendalam

Aplikasi web statis siap hosting di **GitHub Pages** untuk membantu guru SMP merancang Rencana Pelaksanaan Pembelajaran (RPP) / Modul Ajar secara bertahap dan menghasilkan file dokumen siap unduh.

## Fitur Utama
1. **Alur Wizard 5 Tahap:** Materi & CP/TP $ightarrow$ Pedagogi & Profil Lulusan $ightarrow$ Komponen Skenario $ightarrow$ Asesmen & Rubrik $ightarrow$ Format Dokumen.
2. **Database 11 Mata Pelajaran Utama SMP (Fase D):** Bahasa Indonesia, Matematika, IPA, IPS, Bahasa Inggris, Pendidikan Pancasila, Informatika, PJOK, PAI, Prakarya, dan Seni Budaya (Kelas VII, VIII, IX, Semester Ganjil & Genap) + opsi mata pelajaran kustom.
3. **Direct Document Generation:** Prompt dirancang agar AI langsung membuatkan file dokumen siap pakai (`.docx`, `.pdf`, Canvas/Canva Docs, atau Google Docs).
